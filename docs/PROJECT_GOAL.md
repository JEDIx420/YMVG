# Project Goal & MVP Scope
Build a secure, highly-performant business directory for YsMen International. 

**Primary User Journeys:**
1. **Public/YsMen Members:** Browse the directory, view static informational pages (Charity, Leadership), and search for specific services using AI semantic search.
2. **Business Owners:** Authenticate via Google OAuth to securely claim, edit, and update their specific directory listing.
3. **Administrators:** Securely upload bulk CSV data to populate the directory and manage the platform.

**Success Metrics:** Sub-second page loads, perfect SEO indexing via Server-Side Rendering (SSR), and zero data leakage between user profiles.
